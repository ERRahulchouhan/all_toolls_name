17. RAG evaluation
This should be a major part of your learning.

Open/open-core tools include:
- Ragas
- DeepEval
- TruLens
- Arize Phoenix
- Opik
- Giskard
- ARES
- RAGChecker
- AutoRAG
- Tonic Validate
- continuous-eval
- Evidently
Common metrics:

Hit Rate, Precision@K, Recall@K, MRR, MAP, nDCG, Context Precision, Context Recall, Faithfulness, Answer Relevance, Correctness

RAG evaluation should separately evaluate retrieval and generation, rather than relying on one overall score. GitHub
18. Agent evaluation
Agent evaluation needs additional metrics:
- task completion
- tool selection accuracy
- tool argument accuracy
- trajectory correctness
- step efficiency
- planning quality
- goal completion
- hallucination
- recovery after tool failure
- latency
- token usage
- cost
- safety violations
Useful tools include DeepEval, Ragas, Phoenix, Opik, Langfuse and custom LLM-as-judge pipelines.
