# Open-Source AI Learning Roadmap

A practical guide to the open-source tools and concepts used to build modern RAG and agentic AI systems.

## Explore the roadmap

The [Open-Source RAG & Agentic AI Roadmap](./OPEN_SOURCE_ROADMAP.md) organizes the landscape into clear sections, from RAG foundations through agent frameworks, evaluation, and production engineering.

It also includes a reference architecture and a suggested project-based learning path. Use it as a guide, not a checklist: choose tools based on what you are building.
